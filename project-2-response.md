### Task 9:

I was not assigned a team so I selected one that I was drawn to from the discord server. I chose [Kerven and Rayvhaun’s project](https://github.com/yatsukki/cart263/tree/main/Project2). This project was them improving and working more on project 1, adding more features. I was definitely a fan of the aesthetics presented, due to the mix of nostalgia and playfulness. Unfortunately the video file is too large for me to properly view, but I made sure to read the artist statement instead.

We are first presented with a title screen that consists of a floating gameboy in the middle. The background has pixel drawings of an apple, a plane and a strawberry milk carton. After using the space bar to go through the title screen, we are greeted with what seems to emulate a retro style computer home page with the field image, along with the pixel icons.

There are multiple features, such as a gif engine, a drawing software, a music player and a camera. By clicking a cat shaped button, the gif engine shows an array of cute cat gifs. It uses CATAAS API to generate the many options of gifs. This is making me more aware of the possibilities that are possible using API. The drawing app allows users to change the pen size and color, as well as erasing and clearing the board. The music app has around a dozen of tracks available, from many different artists. It was fun to discover some new tracks! Each option also comes with it’s own album picture. I think its fun how it isn’t only one picture. The camera features allows users to take a picture using the front camera. It also allows us to save the most recent one, updating the saved picture each time. I haven’t used a camera feature in my projects yet, so I learnt a lot reading those segments of code. There is a lack of comments within the code, something I also often struggle including, however the code itself is still pretty straightforward.

The general look of the whole site is very consistent. All the graphics, such as the pixelated fonts, chosen images, retro layout as well as the pixel art contribute to the older feel of the website, as if it was a modern take of a relic of the past. The draggable windows are probably my favourite aspect of the whole project. It really makes it feel as if it was someone’s home computer, and not just a web project. You can even “delete” them which is a detail I appreciate. One thing I wonder if it is possible is to change the window overlay order. The order of each windows are predetermined by how they’re coded, and while it is just a minor thing, it would definitely be something cool to add the one most recently clicked to be the top one.
